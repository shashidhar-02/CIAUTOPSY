# CIAUTOPSY Examples & Demonstrations

This directory contains representative CI/CD failure logs and generated diagnosis reports to demonstrate CIAUTOPSY's deterministic root-cause analysis, cascading symptom grouping, and baseline comparison.

## Directory Contents

- `logs/`
  - `failed_python_import.log`: Realistic Python CI failure with a missing dependency (`jwt`), cascading pytest exit errors (`exit code 1`), and simulated tokens that demonstrate automated redaction.
  - `success_baseline.log`: The preceding successful CI run on the same pipeline, used as a baseline to isolate regressions.
  - `ambiguous_failure.log`: An unstructured or unknown CI failure log used to test conservative hypothesis generation when certainty cannot be proven.
- `reports/`
  - `sample_report.md`: Markdown autopsy report generated from `failed_python_import.log`.
  - `sample_report.json`: Machine-readable JSON autopsy report complying with JSON schema v0.1.0.
  - `sample_comparison.md`: Differential Markdown autopsy report generated by comparing `failed_python_import.log` against `success_baseline.log`.

---

## Reproducing the Example Reports

You can re-generate and validate all sample reports locally using the included validation script:

```bash
# Execute the example validation suite
python scripts/validate_examples.py
```

Or run the CLI commands individually:

### 1. Analyze a Failed Run (Terminal Summary)
```bash
ciautopsy analyze examples/logs/failed_python_import.log
```

### 2. Export Detailed Markdown Report
```bash
ciautopsy analyze examples/logs/failed_python_import.log --format markdown --output examples/reports/sample_report.md
```

### 3. Export Machine-Readable JSON
```bash
ciautopsy analyze examples/logs/failed_python_import.log --format json --output examples/reports/sample_report.json
```

### 4. Differential Analysis against Successful Baseline
```bash
ciautopsy analyze examples/logs/failed_python_import.log --baseline examples/logs/success_baseline.log --output examples/reports/sample_comparison.md
```

All analysis runs locally without external network requests or paid LLM APIs.
